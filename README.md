# MSc Approximate Swaption Pricing in an Affine Framework

This repository contains Python code for the simulations and calculations behind the Master's Thesis "Approximate Swaption Pricing in an Affine Framework" by Søren Alexander Christensen, cand.scient.oecon. from the University of Copenhagen.

The notebook Thesis Vasicek2+CIR2.ipynb contains code for Monte Carlo pricing and
Singleton and Umantsev approximation in the 2-factor Vasicek model and the 2-factor CIR model.

The notebook Thesis Vasicek3.ipynb contains code for Monte Carlo pricing and S&U
approxmation in the 3-factor Vasicek model, and plotting relevant joint densities and exercise
boundaries.

The notebook Thesis Taylor.ipynb contains code for Don H. Kim approximation in the 2-factor Vasicek
model and the 2-factor CIR model, and relevant approximation errors.

The notebook Thesis Joint PDF + 2-Factor Exercise Bound Illustration.ipynb contains
code plotting joint densities and exercise boundaries in the 2-factor Vasicek model and
the 2-factor CIR model, and relevant S&U approximation errors.

The notebook Thesis Result Plots.ipynb contains code for plotting swaption prices, normal
volatilities and approximation errors in Section 8.

The notebook Thesis Normal Volatility.ipynb contains code for computing normal volatil
ities, in this case implemented for the 3-factor Vasicek model
